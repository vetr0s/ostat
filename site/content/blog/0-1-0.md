The first version that generates a whole site.

- Content discovery with drafts, future-dating and slug overrides
- Margin notes in the Tufte shape, collapsing to numbered endnotes in the feed
- Tables, strikethrough and syntax highlighting, none of which CommonMark has
- An RSS feed at two addresses, and a sitemap
- Layouts as Odin procedures, with no template language

Set in [ET Book](https://github.com/edwardtufte/et-book), served from this
domain with `font-display: optional`, so the page never trades one typeface for
another while you are reading it.
